# Afrika Integrated Holdings (AFRIH)

A Pan-African economic group website built entirely in C — a custom HTTP server that generates all HTML and CSS programmatically. No separate HTML or CSS files in the source code.

## Architecture

- `afrih_server.c` — Pure C HTTP server using POSIX sockets and pthreads
- All HTML content generated from C string literals
- All CSS embedded as a C `#define` macro
- Multi-threaded request handling
- 5 pages + 404 handler + form submission endpoint

## Pages

| Route     | Page                        |
|-----------|-----------------------------|
| `/`       | Home — hero, stats, overview |
| `/about`  | Vision, mission, principles  |
| `/sectors`| 12 economic sectors         |
| `/roadmap`| 10-year strategic timeline  |
| `/contact`| Contact form                |

## Build & Run (Local)

```bash
gcc afrih_server.c -o afrih_server -lpthread
./afrih_server
# Open http://localhost:8080
```

## Deployment

The static HTML files in this repo are generated by compiling and running the C server. They are served via GitHub Pages.
